# ACME — Калькулятор дней рождения

Веб-сервис на Django для хранения дат рождения и подсчёта дней до ближайшего праздника. Если день рождения сегодня — сервис поздравит именинника, если в другой день — покажет точное количество оставшихся дней.

## Основной функционал

* **Калькулятор дней рождения:** автоматический расчёт дней до ближайшего дня рождения с учётом високосных лет и валидацией реального возраста.
* **CRUD для записей:** создание, просмотр, редактирование и удаление карточек именинников (с возможностью загрузить фото).
* **Система прав доступа:** создавать записи могут только авторизованные пользователи, а редактировать и удалять — исключительно автор записи.
* **Поздравления и пагинация:** возможность оставлять поздравления на странице именинника и постраничный вывод общего списка записей.

## Стек технологий

* Python 3.9+
* Django 3.2
* Django Bootstrap 5 (`django-bootstrap5`)
* Pillow (работа с изображениями)
* SQLite

## Структура проекта

* `acme_project/` — корневая директория Django-проекта (настройки, главные маршруты, общие шаблоны).
* `birthday/` — основное приложение: модели `Birthday` и `Congratulation`, формы, валидаторы, CBV-представления и логика подсчёта дней.
* `pages/` — статичные страницы (главная страница со счётчиком записей).
* `core/` — служебное приложение (кастомные страницы ошибок).
